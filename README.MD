# Understanding CORS and Preflight Requests

This repository contains my internship assignment on Cross-Origin Resource Sharing (CORS) and Preflight Requests.

## Objectives

* Understand CORS and its role in web security.
* Learn how browsers enforce cross-origin restrictions.
* Explore simple requests and preflighted requests.
* Investigate CORS behavior using browser DevTools.
* Analyze common CORS errors and their solutions.
* Learn from a real-world CORS issue discussed with a senior developer.

## Contents

* Concept explanations for CORS-related topics.
* Practical investigation of different cross-origin request scenarios.
* Analysis of request and response headers.
* Real-world CORS problem and key takeaways.
